# Security policy

Mitra can operate a whole phone, so safety bugs matter more than features.

**Please report privately**, not in a public issue: open a GitHub Security Advisory on this repository.
Include the Android version, the app and steps, and which trust rule (R1–R14) you expected to fire.

In scope: any way to make Mitra act without the trust engine, type into secret fields, act on payment screens,
follow instructions from web pages or messages (prompt injection), or bypass the Stop button.
